# Orbit

An interactive Solar System atlas with eight planets, the Sun, a date-based orbital model and time controls. Built with HTML, CSS, Canvas 2D and vanilla JavaScript.

**[Explore Orbit](https://mnerst1.github.io/Orbit/)**

## Features

- Select planets on the map, in the menu or with number keys 1–8
- Planet cards with equatorial diameter, orbital period and sidereal rotation period
- Date picker and timeline covering 1800–2050
- Pause, reverse time and choose 1, 10, 30, 100 or 365 simulated days per second
- Drag to pan, zoom with the wheel or pinch gestures, and reset the camera
- Oblique and overhead views; orbit and label toggles
- Compact orbit spacing or a common proportional distance scale
- Procedural planet illustrations, Saturn's rings and a deterministic star field
- Mobile layout, keyboard navigation and reduced-motion support
- No backend, dependencies or build step

## Run locally

Open `index.html` in a modern browser, or serve this directory using a static HTTP server. Google Fonts are optional and fall back to system fonts.

## Model and limitations

Positions are calculated from NASA/JPL's Table 1 Keplerian elements and rates for 1800–2050, solving Kepler's equation with Newton iteration. Earth uses the Earth–Moon barycenter. UTC timestamps approximate the model's dynamical time; this is an educational visualization, not a high-precision ephemeris or a telescope-pointing tool.

In compact mode, each orbit is scaled separately. Proportional mode uses the same distance scale for every planet. The sizes of planets and the Sun are always enlarged independently; their textures, rings and lighting are artistic. The plane is projected into Canvas 2D, with orbital inclination included. Rotation periods in the cards are sidereal periods, not solar days; the ↺ symbol indicates retrograde rotation.
